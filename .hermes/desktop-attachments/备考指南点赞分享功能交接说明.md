## 二、用户需求

在“备考指南”文章详情页底部增加：

1. 点赞按钮和点赞数
2. 分享按钮
3. 分享到微信群时可正确显示文章标题
4. 分享卡片有文章缩略图
5. 分享卡片有摘要/描述
6. 点击分享卡片后进入对应文章详情页，用于引流

## 三、建议实现范围

### 1. 文章详情页底部操作栏

建议在正文和“相关阅读”之间增加操作栏，至少包含：

- 点赞图标
- 当前点赞数
- 分享图标
- 点赞后的选中状态
- 加载中、成功和失败提示

按钮需要适配手机宽度，避免遮挡正文或相关阅读内容。

### 2. 点赞功能

需要先确认项目已有的身份体系，再选择唯一点赞身份：

- 已登录网站：使用用户 ID
- 微信环境已有 OpenID：使用 OpenID
- 没有登录体系：至少使用签名 Cookie 防止同一浏览器重复点赞

推荐后端接口（实际命名应遵循项目现有风格）：

```text
GET  /api/articles/:articleId/engagement
POST /api/articles/:articleId/like
```

推荐数据约束：

- 点赞表增加唯一约束：`article_id + user_id`（或 `openid`）
- 重复点赞请求返回幂等结果，不重复增加计数
- 点赞数以服务端结果为准，不能只保存在前端
- 文章不存在、已下线、未登录等情况返回明确错误

如果产品需要取消点赞，再增加：

```text
DELETE /api/articles/:articleId/like
```

### 3. 微信分享功能

微信内网页要稳定设置自定义标题、摘要、缩略图和链接，需要接入微信 JS-SDK，不能只依赖前端页面的 `document.title`。

前端流程：

1. 获取当前文章的分享数据
2. 向服务端请求当前 URL 的 JS-SDK 签名配置
3. 调用 `wx.config`
4. 在 `wx.ready` 中配置好友/群聊分享和朋友圈分享
5. 用户点击页面分享菜单时使用文章自己的标题、摘要、链接和缩略图

需要配置的分享字段：

```text
title: 文章标题
desc: 文章摘要，缺失时从正文截取
link: 当前文章的规范 HTTPS URL
imgUrl: 文章封面图的公网 HTTPS URL
```

建议后端增加或复用类似接口：

```text
GET /api/wechat/js-sdk-config?url=<当前页面完整URL>
```

服务端需要使用公众号的 `access_token` 和 `jsapi_ticket` 生成签名，并按微信要求缓存，不能把 AppSecret 放在前端。

### 4. 分享卡片和图片兜底

- 优先使用文章已有封面图
- 封面必须是公网可访问的 HTTPS 地址，不能使用 `localhost`、相对路径或需要登录的图片地址
- 文章没有封面时使用统一的站点默认分享图
- 默认图应有品牌名和“备考指南”识别信息，但不要影响正文首屏
- 标题过长时在分享数据层截断，保留文章核心标题
- 摘要为空时从文章正文去除 HTML 后截取一段
- 文章 URL 使用固定详情页地址，不能使用临时筛选参数或后台地址

### 5. 微信外的降级行为

在普通浏览器中：

- 分享按钮优先调用系统分享 API
- 不支持系统分享时复制文章链接
- 复制成功后给出轻量提示
- 不应因为微信 SDK 加载失败而影响文章阅读和点赞

## 四、接手 agent 的第一步

拿到源码后先定位以下内容，再开始改动：

1. 备考指南文章列表路由
2. 文章详情页组件或模板

4. 现有文章详情接口和相关阅读接口

不要在没有确认技术栈和数据结构的情况下新建一套平行 API 或独立登录体系。

## 五、验收标准

### 点赞

- 文章详情页底部能看到点赞按钮和实时点赞数
- 点击一次只增加一次点赞
- 重复点击或重复请求不会重复计数
- 刷新页面后点赞状态和数量保持正确
- 未登录场景按项目规则给出登录提示或幂等处理
- 文章下线/不存在时不会产生点赞记录

### 微信分享

- 在微信内打开文章，分享给微信群时显示正确标题
- 分享卡片显示文章对应缩略图
- 分享卡片显示摘要或合理的正文摘要
- 群内点击卡片可进入对应文章详情页
- 不同文章的分享标题、图片和 URL 不串数据
- 从分享链接进入后页面可正常加载，点赞和相关阅读仍可用
- 微信 SDK 签名失败时，页面正文不受影响，并有可用降级分享方式

### 回归检查

- 移动端底部操作栏不遮挡正文、相关阅读和返回顶部控件
- 点赞接口有未登录、重复请求、文章不存在等测试
- 分享配置接口不会泄露 AppSecret
- 分享 URL、图片 URL 均为生产环境 HTTPS 地址
- 完成真实微信内测试，不能只用普通桌面浏览器代替
