## 1. 活动规则设计

### 1.1 核心机制（当前方案 + 优化）

```
规则速览：
- 价格：399元/月（周一~周五，每天1节课）
- 拉新：每成功邀请1人报名缴费 → 推荐人减100元
- 封顶：拉4人 → 当月免费（即 399 - 4×100 = 0）
```

### 1.2 优化方案：分段激励

| 已拉人数 | 原方案 | 优化方案 | 效果 |
|---------|--------|---------|------|
| 第1人 | 减100 → 299元 | **减150 → 249元** | 第一单冲击力加倍 |
| 第2人 | 减100 → 199元 | **减100 → 149元** | 保持推力 |
| 第3人 | 减100 → 99元 | **减100 → 49元** | 临近免费更有动力 |
| 第4人 | 减100 → 0元 | **减49 → 0元** | 免费达成 |

**为什么有效：** 第1人减150元比减100元冲击大得多（心理上「省了一半多」），家长最愿意在朋友圈说"我推荐朋友省了150"。

### 1.3 优化方案：双向激励

```
原方案：推荐人 → 减100
优化后：推荐人 → 减100  |  被推荐人 → 也减100
```

**场景：**
- 妈妈A推荐妈妈B → A减100、B也减100
- 妈妈们互相推荐时更有底气
- 被推荐的人从「被推销」变成「有优惠」，转化率提升

### 1.4 文案模板

> **家长转发文案（微信朋友圈/群）：**
> "我家娃在满分虎上了两周，体能进步挺明显的！现在活动期，推荐朋友我俩各减100元，一起报更划算～"
>
> **教练话术：**
> "XX妈妈，您现在推荐一个朋友来报名，您直接减150元，朋友还减100元，相当于两个人一起省250！"

## 2. 技术实现方案

利用你现有的**打卡精灵系统**（`manfenhu.com/elf/`）+ **后台管理系统**实现裂变追踪。

### 2.1 不需要新系统

你的**后台管理（admin.js）**已经具备：
- ✅ 学生管理（增删改查）
- ✅ 积分系统（points）
- ✅ 数据同步（API双向同步）
- ✅ 批量操作

**裂变追踪不需要额外开发独立的裂变系统**，用现有积分功能即可实现。

### 2.2 推荐追踪方案（运营驱动，零开发）

利用你现有的**后台 + 手动物料**，不需要写一行代码：

| 步骤 | 操作 | 谁执行 |
|------|------|--------|
| 1 | 给每个学员发**5张纸质推荐卡**（印二维码），卡上写学员姓名 | 机构制作 |
| 2 | 新家长持卡到店报名 → 报出推荐人姓名 | 前台登记 |
| 3 | 前台在后台找到旧学员 → 点击 `💰分配金币` → 加相应积分 | 前台操作 |
| 4 | 新学员也在后台新增 | 前台操作 |

**积分换减免规则：**
```
100积分 = 100元（1:1 兑换减免）
学员满减时，前台在后台直接修改积分 → 减免对应金额
```

### 2.3 可选：推荐卡二维码自动识别（需轻量开发）

如果你想让家长用手机扫码自动记录推荐关系，可以增加一个**轻量推荐页面**在现有网站上：

**开发量：** 新增1个HTML页面（`public/elf/refer.html`） + 后台加一个「推荐记录」Tab

## 5. 运营执行SOP

### 5.1 每日运营流程

```
每日运营流程（前台/教练）：
───────────────────────────────────

① 早上：检查推荐卡库存 → 发给有需要的学员
② 课间：教练口头提醒「有朋友一起来上课更划算」
③ 放学：前台主动跟接孩子的家长介绍活动
④ 晚上：在家长群发一张分享图 + 一句话提醒
⑤ 睡前：记录当天新增推荐数 → 核对后台数据
```

### 5.2 家长引导话术

**场景1：接孩子时**
> 前台："XX妈妈，我们最近有个活动，您推荐身边的朋友来报名，您直接减150，朋友也减100。像平时一起接孩子的那些妈妈，您可以推荐一下～"

**场景2：家长主动咨询**
> 教练："咱们399的月卡非常划算，现在推荐朋友来还能省钱。您平时朋友圈里有孩子差不多大的家长吗？推荐一下您省150，他们也省100，双赢。"

**场景3：推荐后的跟进**
> 前台收到推荐后，**24小时内**发微信给推荐人：
> "XX妈妈，您推荐的朋友已经联系我们了，您的减免已记录！再推荐X个人就能免费了，加油👏"

### 5.3 前台登记流程

```
新家长到店 → 询问「哪位家长推荐的您？」
          → 在后台找到推荐人
          → 点击「💰分配金币」加150积分（代表已推荐1人）
          → 新增新学员资料
          → 给新学员加100积分（双向激励）
          → 记录到「推荐记录表」（纸质或后台）
```

## 7. 效果预期与风险控制

### 7.1 预期效果

以**当前50个在籍学员**为基础：

| 参与度 | 参与人数 | 人均推荐 | 新增付费 | 免费名额成本 |
|--------|---------|---------|---------|------------|
| 悲观(20%) | 10人推荐 | 1.5人 | 15人 | ~3个免费 |
| 正常(40%) | 20人推荐 | 2.5人 | 50人 | ~8个免费 |
| 乐观(60%) | 30人推荐 | 3.5人 | 105人 | ~18个免费 |

**正常情景：50个新增付费用户，8个免费名额**
- 营收：50 × 399 - 8 × 399 = **16,758元**（净增）
- 获客成本：约 79元/用户（远低于正常300-500元）
- 下月续费：如果课程好，大部分会续费→长期收溢

### 7.2 风险控制

| 风险 | 概率 | 应对方案 |
|------|------|---------|
| 恶意刷推荐（一人多号） | 低 | 到店验证，实名制，线下核销 |
| 竞争对手模仿 | 中 | 先发优势，家长群先行占领 |
| 场地容量不足 | 中 | 设定「本月推荐名额上限」，满员截止 |
| 家长嫌麻烦不愿意推 | 中 | 简化流程➕实物推荐卡降低操作门槛 |
| 活动结束后退课潮 | 低 | 课程质量是核心，活动只是引流 |

### 7.3 场地容量测算

```
399月卡：周一~周五（约22天/月），每天1节课
假设有3个教练，同时上3节课（每节课8-10人）

日容量上限：3班 × 10人 = 30人/节 × 轮流排课
≈ 60-90人/天（分时段）

可容纳学员上限：~80-120人（现有+新增）
超过此数 → 建议限制活动名额或新增教练
```
